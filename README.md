# Rankline Driving School Website

A responsive Next.js website starter for Rankline Driving School in Juja, Kiambu County.

## Included
- Premium black, white and gold visual identity
- Responsive desktop and mobile navigation
- Home, approach, Class B course, contact and opening-soon sections
- Click-to-call and WhatsApp enquiry links
- Basic SEO metadata
- Responsive styling

## Requirements
- Node.js 20.9 or later
- npm

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Production build

```bash
npm run build
npm start
```

## Before publishing
1. Confirm the school's final opening date and enrolment process.
2. Confirm course fees, lesson duration and training schedule before publishing them.
3. Replace the sample stock photography with real photos of the school's training car, instructor and lessons (with permission).
4. Confirm the exact public business address before adding a map.
5. Confirm the school is authorized and ready to offer the advertised training before changing the "preparing to open" wording.
6. Add a privacy notice before collecting personal information through a booking form.
7. Connect a domain and deploy to Vercel or another Next.js host.
